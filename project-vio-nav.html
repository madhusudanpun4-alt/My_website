Technical project · 2025 – 2026

Hybrid Visual Navigation for Autonomous UAVs

ROS Gazebo Python IMU Stereo Vision

Overview

GPS signals disappear indoors, near tall structures, and in other cluttered environments — exactly where small UAVs are often most useful. This project built a Visual-Inertial Odometry (VIO) platform that lets a UAV estimate its own position and orientation without GPS, by tightly coupling data from an IMU (accelerometer + gyroscope) with a stereo camera pair.

Approach

  • Implemented state estimation through tight coupling of IMU and stereo-camera data, rather than treating each sensor independently.
  • Fused accelerometer, gyroscope, and visual feature data to achieve robust 6-DOF (six degrees of freedom) pose estimation in obstacle-dense environments.
  • Built a scalable simulation framework in ROS and Gazebo to validate navigation algorithms in high-fidelity virtual flight environments before any hardware deployment.
  • Defined localization accuracy and obstacle-avoidance success metrics, and validated performance against ground-truth trajectories inside the simulation environment.
  • Coordinated software, sensing, and testing workflows across a multidisciplinary team, maintaining documentation of algorithm iterations and test results throughout.

Role

Led development of the VIO platform end-to-end — from algorithm design through simulation validation — while coordinating with teammates working on sensing hardware and testing infrastructure.
